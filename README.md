# 返事

佐伯と看護師ユウの一夜を、言葉と余白で読むインタラクティブ短編。v1.0.0 の保存用一式です。

## 読む

`henji.html` をブラウザで開きます。インストール・ビルド・外部通信は不要です。

- **物語を読む**：会話の分岐と余白を中心に読む。約10〜15分。
- **立ち止まりながら読む**：3場面の問いと、回答に応じた解説を加える。約15〜20分。
- 「戻る」、途中再開、文字サイズ変更、表示アニメーションを省く設定があります。
- 読書位置はブラウザの localStorage に保存します。ブラウザ設定やファイルの開き方によっては保存できません。
- すべての物語分岐は同じ終幕に合流します。結末の優劣や性格の採点はありません。
- 終幕の「選んだ言葉を振り返る」から、選択と反応を確認し、場面に戻れます。

フィクションです。実際の看護手順を学ぶ教材ではありません。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `henji.html` | 本文・問い・表示・進行処理を含むゲーム本体。編集の正本 |
| `docs/story.md` | 全38場面と分岐先を読み比べるための原稿（自動出力） |
| `docs/checkpoints.md` | 3場面の問い・選択肢・解説（自動出力） |
| `docs/design.md` | 人物、設計意図、v1の範囲と制約 |
| `scripts/export-story.cjs` | 本体から原稿と問いを再出力するスクリプト |
| `tests/story.test.cjs` | 分岐・問い・履歴・保存の確認 |
| `CHANGELOG.md` | バージョン記録 |

## 編集と確認

Node.js 18以上があれば実行できます。追加パッケージのインストールは不要です。

```sh
npm test
npm run docs
```

本文や問いは `henji.html` を編集し、上のコマンドで動作確認と原稿の再出力を行ってください。`docs/story.md` と `docs/checkpoints.md` の直接編集は再出力時に上書きされます。

テストは簡易DOMでの動作確認です。通常・ガイド付きの全432経路ずつ（合計864経路）、問いの出現、回答・スキップ、終幕からの戻る操作、振り返り、保存位置の再開、回答の巻き戻し、旧保存形式の読み込みを確認します。全ての問いの回答の直積を網羅するテストではありません。実ブラウザの表示、操作感、スクリーンリーダーでの確認は別途必要です。

## Gitに記録する

新規リポジトリなら、このフォルダで次を実行します。

```sh
git init -b main
git add .
git diff --cached --stat
git commit -m "Release Henji v1.0.0"
git tag -a v1.0.0 -m "Henji v1.0.0"
```

既存のリポジトリに入れる場合は `git init` を実行せず、適切なフォルダにこの一式を置いてコミットします。リモートへのアップロードは、保存先を確認してから行ってください。

```sh
git remote add origin <リポジトリURL>
git push -u origin main
git push origin v1.0.0
```

この一式はファイル準備用です。リモート設定・コミット・タグ作成・公開はまだ行っていません。公開や再配布に適用するライセンスは未設定です。
